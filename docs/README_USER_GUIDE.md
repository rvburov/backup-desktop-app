## Установка

### Системные требования

- **Windows**: Windows 10/11, Python 3.8+
- **Linux**: Ubuntu 18.04+, CentOS 7+, Python 3.8+
- **macOS**: macOS 10.14+, Python 3.8+
- 100 МБ свободного места
- Разрешения на чтение/запись файлов

### Установка на Windows

```bash
# Скачайте Python с python.org
pip install -r requirements.txt
python backup-app.py
```

Готовый `BackupApp.exe` (см. руководство разработчика, раздел «Процесс сборки») запускается без установки Python.

### Установка на Linux

```bash
sudo apt update
sudo apt install python3 python3-pip
pip3 install -r requirements.txt
python3 backup-app.py
```

### Установка на macOS

```bash
brew install python3
pip3 install -r requirements.txt
python3 backup-app.py
```

### Запуск в фоне

```bash
python backup-app.py --minimized
```

Окно не открывается, приложение сразу появляется в системном трее и работает по расписанию.
Так же оно запускается при включённом автозапуске.

## Интерфейс приложения

### Главное окно

Приложение имеет интуитивно понятный интерфейс с двумя основными вкладками:

#### Вкладка "Выбор файлов"

- **Вкладки** - возможность создания нескольких наборов файлов для копирования
  - Кнопка "+ Добавить вкладку" для создания новых наборов
  - Возможность закрытия вкладок (кроме последней)
- **Список выбранных папок** - управление директориями для копирования
  - Кнопки: "Добавить папку", "Удалить выбранную", "Очистить список"
- **Список выбранных файлов** - отдельные файлы для резервирования
  - Кнопки: "Добавить файлы", "Удалить выбранный", "Очистить список"
- **Папка сохранения** - выбор места сохранения резервных копий

#### Вкладка "Настройки"

- **Планирование** - настройка автоматического расписания копирования
  - Тип периода: Ежедневно, Еженедельно, Ежемесячно
  - Время копирования
  - День недели/месяца (для соответствующих периодов)
- **Дополнительные настройки** - расширенные параметры:
  - **Копировать данные всех вкладок** - одновременное копирование из всех созданных вкладок
  - Копировать только содержимое папок, без самих папок
  - Добавить дату к имени сохраненной копии файла
  - Создавать отдельную папку "Резервное копирование дд-мм-гггг"
  - **Автозапуск при входе в систему** - приложение запускается свёрнутым в трей
  - **Фоновый режим работы** - при закрытии окна приложение остаётся в трее и копирует по расписанию
  - Уведомления о начале и результате копирования
  - **Выполнять пропущенное копирование при следующем запуске** - если в назначенное время компьютер был выключен
- **Безопасность** - максимальный размер копируемого файла и краткое описание правил безопасности
- **Сброс настроек** - восстановление настроек по умолчанию

### Панель управления

- **Запустить** - включение автоматического копирования по расписанию
- **Остановить** - остановка автоматического копирования
- **Копировать** - выполнение немедленного ручного копирования
- **Отменить** - отмена текущей операции копирования
- **История копирования** внизу окна - когда и что копировалось и чем закончилось, подробнее
  в разделе [История копирования](#история-копирования); кнопка «Открыть подробный журнал» рядом

Те же действия доступны из меню иконки в системном трее (правая кнопка мыши): «Открыть окно»,
«Копировать сейчас», время следующего копирования и «Выход».

## Первое использование

### Шаг 1: Работа с вкладками

1. **Создание вкладок**: Нажмите "+ Добавить вкладку" для создания нового набора файлов
2. **Переименование**: Кликните на заголовок вкладки для редактирования названия
3. **Закрытие**: Используйте крестик на вкладке для закрытия (нельзя закрыть последнюю вкладку)

### Шаг 2: Добавление источников данных

1. Откройте нужную вкладку в разделе "Выбор файлов"
2. Нажмите "Добавить папку" для выбора директорий для резервирования
3. Используйте "Добавить файлы" для выбора отдельных файлов
4. Убедитесь, что выбранные элементы появились в соответствующих списках

### Шаг 3: Выбор папки назначения

1. Нажмите "Выбрать папку" рядом с полем "Папка сохранения"
2. Выберите существующую папку или создайте новую для резервных копий
3. Убедитесь, что на выбранном диске достаточно свободного места

### Шаг 4: Настройка параметров копирования

1. Перейдите на вкладку "Настройки"
2. Настройте дополнительные параметры:
   - **Копировать данные всех вкладок** - позволяет выполнять массовое копирование
   - **Копировать только содержимое папок** - копирует только файлы из папки, без создания самой папки в назначении
   - **Добавить дату к имени** - предотвращает перезапись файлов, добавляя временную метку
   - **Создавать отдельную папку** - организует копии по датам

### Шаг 5: Настройка расписания (опционально)

1. Выберите тип периода:
   - **Ежедневно** - копирование каждый день в указанное время
   - **Еженедельно** - копирование в выбранный день недели
   - **Ежемесячно** - копирование в указанный день месяца
2. Установите время копирования
3. Для еженедельного/ежемесячного периода укажите соответствующий день

### Шаг 6: Запуск копирования

- **Автоматический режим**: Нажмите "Запустить" для работы по расписанию
- **Ручной режим**: Нажмите "Копировать" для немедленного выполнения
- **Отслеживание прогресса**: Наблюдайте за ходом выполнения в прогресс-баре и логе операций

## Расширенные настройки

### Многовкладочное копирование

**Новая функция**: Копирование из нескольких вкладок одновременно

- Включите опцию "Копировать данные всех вкладок"
- Каждая вкладка копируется в свою папку назначения
- Идеально для организации резервных копий разных проектов

### Пакетное копирование

**Альтернативное название**: Массовое копирование из всех профилей

- Одновременная обработка всех настроенных вкладок
- Независимые пути назначения для каждого набора данных
- Сводный прогресс по всем операциям

### Настройка автозапуска

Приложение может автоматически запускаться при входе в систему:

1. Установите галочку "Автозапуск при входе в систему"
2. Приложение автоматически настроит автозапуск для вашей ОС:
   - **Windows**: запись в реестр (HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run)
   - **Linux**: создание .desktop файла в ~/.config/autostart/
   - **macOS**: создание plist файла в ~/Library/LaunchAgents/
3. Для отключения снимите галочку

При входе в систему приложение стартует сразу в трей, без окна и без окна консоли.
Если расписание было включено, оно продолжает работать.

### Фоновый режим и системный трей

- **Закрытие окна** (крестик) или сворачивание прячет приложение в трей, расписание продолжает работать.
  Чтобы завершить приложение, выберите «Выход» в меню иконки в трее.
- **Открыть окно**: двойной щелчок по иконке в трее или пункт меню «Открыть окно».
  Повторный запуск приложения тоже просто показывает окно уже работающего экземпляра.
- **Уведомления** появляются при начале планового копирования и по его окончании:
  успех, завершение с ошибками (сколько файлов не удалось скопировать) или отмена.
- **Пропущенное копирование**: если компьютер был выключен в назначенное время, копирование
  выполняется через несколько секунд после следующего запуска приложения. Эту функцию можно отключить
  в настройках.
- **Пока идёт копирование**, новое не запускается: плановый запуск, совпавший с ручным, пропускается
  с записью в истории копирования.
- **Недоступные пути** (отключённый внешний диск, сетевая папка) подсвечиваются в списках красным
  и пропускаются при копировании, но из настроек не удаляются.
- Чтобы при закрытии окна приложение завершалось, как раньше, снимите галочку
  «Фоновый режим работы».
- **Сбои самого приложения**, например если не удалось сохранить настройки, показываются
  предупреждением: в открытом окне диалогом, при работе в трее уведомлением. Такое уведомление
  появляется, даже если уведомления о копировании выключены.

### Стратегии именования файлов

- **Добавить дату к имени** - добавляет временную метку формата "дд.мм.гггг_ЧЧ-ММ-СС" к копируемым файлам, предотвращая перезапись
- **Числовые суффиксы** - при отключенной истории добавляет суффиксы (_(1), _(2)) к конфликтующим файлам
- **Создавать отдельную папку** - создает папку с названием "Резервное копирование дд-мм-гггг" для каждого сеанса копирования

### Режимы копирования папок

- **Копировать всю папку** - сохраняет структуру папок (по умолчанию)
- **Копировать только содержимое папок** - копирует только файлы из папки без создания самой папки в месте назначения

### Мониторинг процесса

- **Прогресс-бар** показывает ход копирования больших объемов данных
- **Статусная строка** отображает текущую операцию и следующий запланированный сеанс

### История копирования

Блок «История копирования» внизу окна показывает только то, что связано с копированием данных:

- начало каждого копирования: ручное или по расписанию и какие вкладки копируются;
- итог: успешно, с ошибками, не выполнено или отменено, сколько файлов скопировано;
- под итогом с отступом: какие файлы не скопированы и почему, например «файл занят другой программой»,
  а также файлы больше лимита размера и со слишком длинным путём;
- плановое копирование не запустилось и почему;
- пропущенное копирование, которое выполняется после запуска;
- копирование, прерванное закрытием приложения;
- запуск и остановка расписания.

Пример:

```
06.10.2026 09:00  Плановое копирование: Документы, Фото
06.10.2026 09:02  ✓ Успешно скопировано 152 файла
07.10.2026 09:00  ✗ Плановое копирование не запущено: Не выбрана папка назначения
08.10.2026 09:01  ⚠ Скопировано 150 файлов, ошибок: 1
                    Не скопирован C:\Документы\отчёт.docx: файл занят другой программой
```

История сохраняется между запусками в файле `history.txt` рядом с настройками
(Windows: `%LOCALAPPDATA%\BackupApp\history.txt`). Записи старше года удаляются автоматически.
У одного копирования показываются первые 20 файлов с ошибками, остальные есть в подробном журнале.

### Подробный журнал

Кнопка «Открыть подробный журнал» открывает файл со всеми сообщениями программы: служебные записи,
технические подробности ошибок и записи правил безопасности с меткой [SECURITY]. Файл лежит
в `logs/backup-app.log` рядом с настройками (Windows: `%LOCALAPPDATA%\BackupApp\logs\backup-app.log`).
Журнал нужен, если по истории копирования не удаётся понять причину ошибки.

## Безопасность и защита данных

### Встроенные механизмы безопасности

#### Защита от переполнения путей

- Путь копии не длиннее 240 символов: такие копии открываются в Windows без настройки длинных путей
- Слишком длинное имя файла укорачивается: начало имени и расширение сохраняются, добавляется метка вида `~1a2b3c4d`, чтобы разные файлы не получили одно имя
- Если слишком длинным получается путь самой папки, эта папка пропускается

#### Безопасная обработка символьных ссылок

- **Символьные ссылки и junction внутри выбранных папок не копируются.** Это защищает от бесконечной петли, когда ссылка указывает на свою же папку, и от копирования данных за пределами выбранной папки
- Каждая пропущенная ссылка записывается в журнал
- Скрытые системные ссылки Windows в папке «Документы» («Моя музыка», «Мои рисунки», «Мои видеозаписи») тоже пропускаются, поэтому копирование «Документов» не заканчивается ошибками доступа
- Если ссылку выбрать источником вручную, копируется содержимое, на которое она указывает, а в журнал пишется пометка

#### Защита от выхода за пределы папки назначения

- Путь каждой копии проверяется: файл не может быть записан вне выбранной папки назначения
- Относительные пути с переходом «..» не используются
- Если папка назначения лежит внутри копируемой папки, при обходе она пропускается, поэтому прошлые копии не попадают в новые
- Папка, которая совпадает с папкой назначения, не копируется

#### Проверка типов файлов

- Копируются только обычные файлы и папки
- Специальные файлы Linux и macOS пропускаются: именованные каналы, сокеты, устройства

### Ограничения безопасности

- **Максимальный размер файла**: по умолчанию 2 ГБ. Лимит меняется в разделе «Настройки», группа «Безопасность»; значение 0 снимает ограничение
- **Максимальная длина пути копии**: 240 символов
- **Системные папки** нельзя выбрать источником или папкой назначения, а при обходе папок они пропускаются:
  - Windows: папка Windows, Program Files, Program Files (x86) и Recovery на системном диске, а на любом диске корзина `$Recycle.Bin`, `System Volume Information` и файлы `pagefile.sys`, `hiberfil.sys`, `swapfile.sys`
  - Linux: `/bin`, `/boot`, `/dev`, `/etc`, `/lib`, `/lib32`, `/lib64`, `/libx32`, `/proc`, `/sbin`, `/sys`, `/usr`
  - macOS: `/System`, `/bin`, `/sbin`, `/usr`, `/dev`, `/etc`, `/private/etc`, `/cores`

### Мониторинг безопасности

Все события безопасности записываются в журнал с меткой "[SECURITY]":

- пропущенные ссылки и junction
- пропущенные системные папки и файлы
- специальные файлы и файлы больше лимита
- укороченные имена и слишком длинные пути
- небезопасные пути и папка назначения внутри копируемой папки
- ошибки доступа к папкам

Пропуски по правилам безопасности не считаются ошибками. Итог копирования показывает их число, например
«Успешно скопировано 120 файлов; пропущено по правилам безопасности: 3». Ошибки доступа к папкам считаются
ошибками копирования. Если однотипных записей за одно копирование больше 200, в журнал попадают первые 200
и итоговое число.

## Решение проблем

### Общие проблемы

#### Приложение не запускается

**Ошибка**: `ModuleNotFoundError: No module named 'PyQt5'`
**Решение**: Установите PyQt5: `pip install PyQt5`

#### Нет прав доступа

**Ошибка**: `PermissionError: [Errno 13] Permission denied`
**Решение**:

- Запустите приложение от имени администратора
- Проверьте права на чтение для исходных папок и запись для папки назначения

#### Недостаточно места

**Ошибка**: Сообщение о недостатке свободного места
**Решение**:

- Освободите место на целевом диске
- Выберите другой диск для сохранения копий
- Исключите большие файлы из резервирования

#### Файлы не копируются

**Проблема**: В логе сообщение "Нет файлов для копирования"
**Решение**:

- Убедитесь, что выбранные папки и файлы существуют
- Проверьте, что в папках есть файлы (не пустые директории)
- Убедитесь, что у приложения есть права на чтение файлов

### Проблемы с многовкладочным копированием

#### Не копируются все вкладки

**Проблема**: Копируется только текущая вкладка
**Решение**: Убедитесь, что включена опция "Копировать данные всех вкладок" в настройках

#### Разные папки назначения

**Особенность**: Каждая вкладка использует свою папку назначения
**Решение**: Проверьте настройки папки сохранения для каждой вкладки отдельно

### Проблемы с пакетным копированием

#### Частичное завершение

**Проблема**: Некоторые вкладки скопированы, другие - нет
**Решение**: Приложение продолжает работу даже при ошибках в отдельных вкладках. Проверьте лог для выявления проблемных вкладок.

#### Несинхронный прогресс

**Особенность**: Прогресс-бар показывает общий прогресс по всем вкладкам
**Решение**: Это ожидаемое поведение. Детальный прогресс по каждой вкладке отображается в логе.

### Проблемы с фоновым режимом

#### Окно закрылось, а приложение «исчезло»

**Особенность**: При закрытии окна приложение сворачивается в трей и продолжает работать
**Решение**: Найдите иконку в трее (на Windows она может быть скрыта за стрелкой «Отображать скрытые значки»); двойной щелчок открывает окно, «Выход» в меню завершает приложение

#### Нет иконки в трее

**Проблема**: Оболочка не поддерживает системный трей (некоторые окружения Linux)
**Решение**: В подробном журнале появляется предупреждение «Системный трей недоступен»; приложение работает по-старому и завершается при закрытии окна. Держите окно открытым или свёрнутым

#### Копирование не выполнилось в назначенное время

**Проверьте**:

- Приложение было запущено (в трее или окном) — таймер работает только внутри приложения
- Расписание включено: кнопка «Запустить» нажата, в окне виден текст «Следующее копирование: …»
- История копирования в окне: в ней видна причина, если плановое копирование не запустилось (нет источников, нет папки назначения, шло другое копирование)
- Если компьютер был выключен, при следующем запуске копирование выполнится автоматически (настройка «Выполнять пропущенное копирование при следующем запуске»)

#### Файл или папка не скопированы по правилам безопасности

**Причина**: Сработало одно из правил безопасности: файл больше лимита, системная папка, ссылка или слишком длинный путь
**Решение**: Файлы больше лимита и со слишком длинным путём перечислены в истории копирования под итогом копирования, остальные случаи записаны в подробном журнале с меткой [SECURITY]. Большие файлы копируются после увеличения лимита в группе «Безопасность»; ссылку можно выбрать источником напрямую; для длинных путей выберите папку назначения ближе к корню диска

#### Системную папку нельзя добавить

**Особенность**: Папки Windows, Program Files и другие системные пути нельзя выбрать источником или папкой назначения
**Решение**: Выберите свои папки с данными. Если нужен весь диск, выберите его корень: системные папки внутри будут пропущены

#### Копирование завершилось «с ошибками»

**Особенность**: Часть файлов не удалось прочитать (заняты другой программой, нет прав), остальные скопированы
**Решение**: Файлы с ошибками и причины перечислены в истории копирования под итогом копирования, полный список есть в подробном журнале. Закройте программы, которые держат файлы, и повторите копирование

### Проблемы с автозапуском

#### Windows

- Проверьте наличие приложения в списке автозагрузки (Диспетчер задач → Автозагрузка)
- При необходимости настройте вручную через реестр: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- Команда автозапуска содержит флаг `--minimized`; при запуске из исходников используется `pythonw.exe`, чтобы не открывалось окно консоли

#### Linux

- Проверьте файл `~/.config/autostart/backupapp.desktop`
- Убедитесь, что файл имеет права на выполнение

#### macOS

- Проверьте настройки в System Preferences → Users & Groups → Login Items
- Убедитесь, что приложение добавлено в список автозагрузки

### Проблемы с копированием

#### Дублирование файлов

**Проблема**: Создаются multiple копии файлов
**Решение**: Отключите опцию "Добавить дату к имени" если хотите перезаписывать файлы

#### Длинные пути

**Проблема**: Ошибки при копировании файлов с длинными путями (Windows)
**Решение**:

- Используйте более короткие имена папок
- Переместите исходные данные ближе к корню диска

#### Символьные ссылки не копируются

**Ожидаемое поведение**: Символьные ссылки пропускаются для безопасности
**Решение**: Если нужно скопировать содержимое ссылки, укажите целевую папку напрямую
