## Установка

### Готовая программа

Готовые программы лежат на странице
[последнего релиза](https://github.com/rvburov/backup-desktop-app/releases/latest). Python
ставить не нужно.

| Система | Файл |
| --- | --- |
| Windows 10 и 11 | `BackupApp-<версия>-windows-x64.exe` |
| macOS на Apple Silicon (M1 и новее) | `BackupApp-<версия>-macos-arm64.dmg` |
| macOS на Intel | `BackupApp-<версия>-macos-x64.dmg` |
| Linux | `BackupApp-<версия>-linux-x64.tar.gz` |

- **Windows**: программа не устанавливается, скачанный файл и есть программа. Положите его
  в постоянную папку, например в «Документы», и запустите.
- **macOS**: откройте образ, перетащите BackupApp в «Программы» и запускайте оттуда.
- **Linux**: распакуйте архив командой `tar -xzf BackupApp-<версия>-linux-x64.tar.gz`
  и запустите `./BackupApp`.

Программа не подписана платным сертификатом, поэтому при первом запуске Windows и macOS
попросят подтверждение. Что нажать, написано в описании релиза. Там же сказано, как
обновиться: настройки и история копирования при обновлении сохраняются.

### Системные требования

- **Windows**: Windows 10 или 11, 64 бит
- **macOS**: macOS 11 и новее, Apple Silicon или Intel
- **Linux**: для готовой программы Ubuntu 22.04 и новее, Debian 12, Fedora 36 и другие
  системы того же возраста и новее; для значка в трее нужна панель с поддержкой трея
- Для запуска из исходников: Python 3.8+
- 100 МБ свободного места
- Разрешения на чтение/запись файлов

### Запуск из исходников на Windows

```bash
# Скачайте Python с python.org
pip install -r requirements.txt
python backup-app.py
```

### Запуск из исходников на Linux

```bash
sudo apt update
sudo apt install python3 python3-pip
pip3 install -r requirements.txt
python3 backup-app.py
```

### Запуск из исходников на macOS

```bash
brew install python3
pip3 install -r requirements.txt
python3 backup-app.py
```

### Запуск в фоне

```bash
python backup-app.py --minimized
```

Окно не открывается, приложение сразу появляется в системном трее и копирует по расписанию.
Так же оно запускается при включенном автозапуске.

## Интерфейс приложения

### Главное окно

Окно называется «Резервное копирование файлов» и состоит из четырех частей:

- **боковая панель слева** — список вкладок и общие команды;
- **рабочая область справа** — выбранная вкладка или страница «Настройки»;
- **история копирования** внизу окна;
- **строка состояния** под историей.

Вкладка — это один набор данных для копирования: что копировать, куда и когда. У каждой вкладки
свое расписание и свои параметры копирования. Например, вкладка «Документы» копируется каждый день
в 09:00, а вкладка «Фото» — по воскресеньям в 22:00 в другую папку.

Все изменения сохраняются автоматически, кнопки «Сохранить» нет.

### Боковая панель

- **ВКЛАДКИ** и число вкладок. Под заголовком — список вкладок. У каждой строки значок состояния,
  название и вторая строка:
  - зеленая точка и расписание: «Каждый день · 09:00», «По воскресеньям · 22:00», «1-го числа · 18:00»;
  - серый кружок и «Расписание остановлено» — вкладка копируется только вручную;
  - оранжевый значок предупреждения и причина: «Не выбраны исходные файлы и папки» или
    «Не выбрана папка назначения» — такую вкладку скопировать нельзя;
  - вращающийся значок и «Подготовка к копированию...», затем «Копирование... 42%» — вкладка
    копируется прямо сейчас.
- **Поиск** «Найти вкладку…» появляется, когда вкладок больше шести. Рядом с заголовком
  тогда видно, сколько вкладок найдено, например «3 из 12». Если ничего не найдено, список
  пишет «Нет вкладок с «…»».
- **Добавить вкладку** — новая пустая вкладка «Без названия», она сразу открывается.
- **Копировать все вкладки** — копирует сразу все вкладки, у которых выбраны источники и папка
  назначения. Вкладки без данных пропускаются молча. Пока идет копирование, кнопка недоступна.
- **Настройки** — общие настройки приложения (см. [Страница «Настройки»](#страница-настройки)).

Ширину боковой панели можно менять: потяните за полосу между панелью и рабочей областью
(от 180 до 440 точек). Двойной щелчок по полосе возвращает ширину по умолчанию. С клавиатуры:
стрелки влево и вправо (с Shift — крупнее), Enter или пробел — ширина по умолчанию.

### Страница вкладки

#### Название и состояние

- **Название** вкладки редактируется прямо в заголовке: щелкните по нему (или по значку карандаша),
  введите новое и нажмите Enter или щелкните в другом месте. Esc отменяет правку. Пустое
  название становится «Без названия».
- **Строка состояния вкладки** под названием:
  - «Следующее копирование: завтра в 09:00» (зеленая) — расписание запущено;
  - «Следующее копирование: остановлено — только ручной запуск» — расписание выключено;
  - причина, по которой вкладку нельзя скопировать (оранжевая);
  - «Идет копирование…».
- **Копировать сейчас** — копирует только эту вкладку. Кнопка недоступна, пока у вкладки нет
  источников или папки назначения и пока идет любое копирование.
- **Корзина** — удалить вкладку (см. [Удаление вкладки](#удаление-вкладки)).

#### Что копировать

- Рядом с заголовком — сводка: «2 папки, 3 файла», при недоступных путях еще «· недоступно: 1»,
  у пустой вкладки — «пока ничего не выбрано».
- **Добавить папку** — выбрать папку, она копируется со всеми вложенными папками.
- **Добавить файл** — выбрать один или несколько отдельных файлов.
- **Очистить список** — убрать все папки и файлы вкладки.
- У каждой строки — значок папки или файла, имя, папка, в которой он лежит, и кнопка «×»
  («Убрать из списка»).
- Путь, который сейчас недоступен (отключен внешний диск, удалена папка), показывается красным
  с пометкой «— недоступен, будет пропущен». Системный путь — «— системный путь, будет пропущен».
  Такие пути из настроек не удаляются: когда диск снова подключен, они копируются как обычно.
- Если папку или файл добавить нельзя (например, это системная папка), внутри блока появляется
  красная плашка «Папка не добавлена» или «Файлы не добавлены» с причиной. Ее закрывает крестик.

#### Папка сохранения

- Поле показывает выбранную папку назначения, кнопка **Выбрать папку** меняет ее.
- Пока папка не выбрана, в поле написано «Папка назначения не выбрана», а ниже — «Без папки
  назначения вкладку нельзя скопировать.»
- Системную папку выбрать нельзя: появится красная плашка «Папка не выбрана» с причиной.

#### Настройки вкладки

Рядом с заголовком напоминание: «действуют только для «Имя вкладки»». Все, что ниже, относится
только к этой вкладке.

Слева — расписание:

- **Копировать по расписанию** — переключатель. Включенный переключатель означает, что расписание
  вкладки запущено; оно работает и в фоне, когда окно спрятано в трей.
- Пока расписание выключено, вместо его настроек виден серый блок: «Расписание остановлено. Вкладка
  копируется только кнопкой «Копировать сейчас» или «Копировать все вкладки».»
- При включенном расписании видны:
  - периодичность: **Ежедневно**, **Еженедельно**, **Ежемесячно**;
  - **Время** копирования;
  - для еженедельного — день недели: Пн, Вт, Ср, Чт, Пт, Сб, Вс;
  - для ежемесячного — **Число** от 1 до 31 (кнопки «−» и «+», по кругу). Для чисел больше 28 видна
    подсказка «В месяцах, где столько дней нет, — в последний день месяца.»;
  - зеленая строка «Следующее копирование: …» — когда расписание сработает в следующий раз.
  Если поменять период, время или день, следующее копирование сразу пересчитывается.

Справа — **Параметры копирования**:

- **Копировать только содержимое папок, без самих папок** — выбранные папки не создаются в месте
  назначения, в него сразу попадает их содержимое.
- **Создавать отдельную папку с названием «Резервное копирование дд-мм-гггг» при каждом копировании** —
  подсказка показывает имя сегодняшней папки, например «Резервное копирование 06-10-2026».
- **Добавить дату к имени сохраненной копии файла** — только при совпадении имен, иначе к имени
  добавляется номер: `файл_(1).txt`.

Внизу блока — **Так будет выглядеть копия**: путь, по которому окажется копия первого источника
вкладки с текущими параметрами, и что будет при совпадении имен. Например:

```
D:/Backup/Резервное копирование 06-10-2026/Документы/Отчет.docx
Ничего не перезаписывается: если папка «Документы» уже есть, копия получит имя
Документы_06.10.2026_14-38-03. Папка с датой одна на день: повторные копирования в тот же день попадают в нее.
```

Пока папка назначения не выбрана, там написано «Сначала выберите папку назначения».

#### Удаление вкладки

Кнопка с корзиной открывает вопрос «Удалить вкладку «Имя»?»: удаляются только настройки этой вкладки,
исходные файлы и уже созданные резервные копии остаются на месте. Кнопка «Удалить вкладку»
подтверждает, «Отмена» — нет. Последнюю вкладку и вкладку, которая сейчас копируется, удалить нельзя.
Если у удаленной вкладки было запущено расписание, оно останавливается, а в истории появляется запись
«Расписание остановлено: Имя».

### Страница «Настройки»

Общие для всех вкладок и сохраняются автоматически. Расписание и параметры копирования здесь не
задаются: они в каждой вкладке.

**Запуск и работа в фоне** — четыре переключателя:

- **Автозапуск при входе в систему** — приложение запускается свернутым в трей. Запущенные расписания
  возобновляются при каждом запуске программы.
- **Фоновый режим работы** — закрытие и сворачивание окна прячут приложение в трей, копирование
  по расписанию продолжается.
- **Уведомления о начале и результате копирования** — всплывающие уведомления у значка в трее.
- **Выполнять пропущенное копирование при следующем запуске** — если компьютер был выключен
  в назначенное время, копирование начнется через несколько секунд после запуска.

**Безопасность**:

- **Максимальный размер файла, ГБ (0 — без ограничения)** — файлы больше лимита пропускаются.
  По умолчанию 2 ГБ.
- Ниже — краткое описание правил безопасности (см. [Безопасность и защита данных](#безопасность-и-защита-данных)).

**Сброс настроек** — кнопка «Сбросить все настройки по умолчанию». После подтверждения
(«Подтверждение сброса», «Да» / «Нет») останавливаются расписания всех вкладок, выключается
автозапуск, а вместо всех вкладок остается одна пустая вкладка «Без названия». История копирования
сохраняется. Пока идет копирование, сброс недоступен.

### История копирования и строка состояния

**История копирования** внизу окна показывает, когда и что копировалось и чем закончилось
(подробнее — в разделе [История копирования](#история-копирования)). Новые записи появляются внизу,
список прокручивается к ним сам.

- Флажок **Только «Имя вкладки»** оставляет записи выбранной вкладки: ее копирования,
  запуск и остановку ее расписания, пропуски.
- **Открыть подробный журнал** — открывает файл журнала программы (см. [Подробный журнал](#подробный-журнал)).

**Строка состояния** под историей:

- во время копирования — значок, что копируется («Подготовка к копированию...», «Копирование «Документы»»,
  «Копирование вкладки 'Фото'...»), полоса хода, текущее действие и кнопка **Отменить**;
- после копирования на 4 секунды — итог: «Копирование завершено успешно», «Копирование завершено
  с ошибками», «Копирование отменено» или «Ошибка копирования»;
- всегда — синяя плашка с ближайшим копированием по расписанию среди всех вкладок:
  «Следующее копирование: завтра в 09:00 · Документы» или «Следующее копирование: остановлено»;
- справа — кнопка **Свернуть историю**; у свернутой истории кнопка называется
  «История копирования (N)», где N — число записей.

Короткие сообщения окна (расписание не запущено, копирование не запущено, сброс выполнен) появляются
на несколько секунд в правом нижнем углу окна. Если окно спрятано в трей, то же сообщение приходит
уведомлением у значка.

### Значок в трее

- Щелчок по значку открывает окно.
- Меню (правая кнопка мыши):
  - **Открыть окно**;
  - **Копировать все вкладки** — то же, что кнопка на боковой панели;
  - ближайшее копирование, например «Следующее копирование: 07.10.2026 09:00 · Документы»
    или «Следующее копирование: остановлено» (только для информации);
  - **Выход** — завершить приложение.
- Подсказка значка — «Резервное копирование файлов» и ближайшее копирование.
- Уведомления (если включены «Уведомления о начале и результате копирования»):
  - «Начато плановое копирование: Документы, Фото» — при запуске по расписанию;
  - итог каждого копирования: «Копирование завершено», «Копирование завершено с ошибками»,
    «Копирование отменено» или «Ошибка копирования» с подробностями, например «Успешно скопировано
    152 файла»;
  - «Копирование не выполнено» с причиной — плановое копирование не запустилось;
  - «Приложение работает в фоне» — когда окно впервые спрятано в трей.

## Первое использование

### Шаг 1: Вкладка

1. При первом запуске уже есть вкладка «Без названия». Щелкните по названию и введите свое,
   например «Документы».
2. Для другого набора данных нажмите «Добавить вкладку» на боковой панели.

### Шаг 2: Что копировать

1. В блоке «Что копировать» нажмите «Добавить папку» и выберите папку.
2. «Добавить файл» добавляет отдельные файлы.
3. Выбранное появится в списке, сводка рядом с заголовком покажет, сколько папок и файлов выбрано.

### Шаг 3: Папка сохранения

1. В блоке «Папка сохранения» нажмите «Выбрать папку».
2. Выберите существующую папку или создайте новую для резервных копий.
3. Убедитесь, что на выбранном диске достаточно свободного места.

### Шаг 4: Параметры копирования

В блоке «Настройки вкладки», справа, отметьте нужное:

- **Копировать только содержимое папок** — в назначение попадают файлы из папки, без самой папки;
- **Создавать отдельную папку «Резервное копирование дд-мм-гггг»** — копии раскладываются по дням;
- **Добавить дату к имени** — при совпадении имен к имени копии добавляется дата и время, а не номер.

Проверьте строку «Так будет выглядеть копия»: она показывает путь будущей копии.

### Шаг 5: Расписание (по желанию)

1. Включите переключатель «Копировать по расписанию». Расписание запускается сразу:
   по умолчанию — каждый день в 09:00.
2. Выберите периодичность: Ежедневно, Еженедельно или Ежемесячно.
3. Установите время, а для еженедельного или ежемесячного периода — день недели или число.
4. Зеленая строка «Следующее копирование: …» покажет, когда копирование выполнится.

Если у вкладки нет источников или папки назначения, расписание не включится: появится сообщение
«Расписание не запущено» с причиной.

### Шаг 6: Копирование

- **По расписанию** — ничего делать не нужно. Окно можно закрыть: приложение останется в трее.
- **Сразу** — «Копировать сейчас» копирует выбранную вкладку, «Копировать все вкладки» — все вкладки
  с данными.
- **Ход копирования** виден в строке состояния и в списке вкладок; «Отменить» прерывает копирование.
  Итог появится в истории копирования.

## Расширенные настройки

### Расписание вкладки

- Расписание у каждой вкладки свое: периодичность, время, день недели или число. Его включает
  и выключает переключатель «Копировать по расписанию» этой вкладки.
- Если у нескольких вкладок время совпало, они копируются вместе, одним копированием.
- Для ежемесячного расписания 29, 30 и 31 число в коротком месяце заменяется последним днем месяца.
- Запущенное расписание сохраняется: после перезапуска приложения или компьютера оно продолжает
  работать. Если к этому моменту у вкладки пропали источники или папка назначения, расписание
  выключается, а в истории появляется запись «✗ Расписание не возобновлено (Имя): причина».

### Копирование нескольких вкладок

- **Копировать все вкладки** (боковая панель или меню трея) копирует все вкладки, у которых выбраны
  источники и папка назначения. Если таких вкладок нет, появится сообщение с причиной
  «Нет вкладок с данными для копирования».
- Каждая вкладка копируется в свою папку назначения со своими параметрами копирования.
- Полоса хода в строке состояния показывает общий ход по всем вкладкам, текст рядом — какая вкладка
  копируется сейчас.
- Итог один на все копирование, например «Успешно скопировано 152 файла из 2 вкладок».

### Настройка автозапуска

Приложение может автоматически запускаться при входе в систему:

1. На странице «Настройки» включите «Автозапуск при входе в систему».
2. Приложение само настроит автозапуск для вашей ОС:
   - **Windows**: запись в реестре (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`)
   - **Linux**: файл `~/.config/autostart/backupapp.desktop`
   - **macOS**: файл `~/Library/LaunchAgents/com.mycompany.backupapp.plist`
3. Чтобы отключить автозапуск, выключите переключатель.

При входе в систему приложение стартует сразу в трей, без окна и без окна консоли.
Запущенные расписания вкладок продолжают работать. Если включить автозапуск не удалось,
появится сообщение с причиной, а переключатель вернется в прежнее положение.

### Фоновый режим и системный трей

- **Закрытие окна** (крестик) или сворачивание прячет приложение в трей, расписания продолжают работать.
  Чтобы завершить приложение, выберите «Выход» в меню значка в трее.
- **Открыть окно**: щелчок по значку в трее или пункт меню «Открыть окно».
  Повторный запуск приложения тоже просто показывает окно уже работающего экземпляра.
- **Пропущенное копирование**: если компьютер был выключен в назначенное время, копирование
  этих вкладок выполняется через несколько секунд после следующего запуска приложения. В истории
  появляется запись «⚠ Пропущено плановое копирование 06.10.2026 09:00, выполняется сейчас (Имя)».
  Функция отключается на странице «Настройки».
- **Пока идет копирование**, новое не запускается: плановое копирование, совпавшее с другим,
  пропускается с записью в истории, ручное — с сообщением «Копирование уже выполняется, новый запуск
  пропущен».
- **Недоступные пути** (отключенный внешний диск, сетевая папка) подсвечиваются в списке красным
  и пропускаются при копировании, но из настроек не удаляются.
- Чтобы при закрытии окна приложение завершалось, выключите «Фоновый режим работы».
- **Сбои самого приложения**, например если не удалось сохранить настройки, показываются
  предупреждением: в открытом окне диалогом, при работе в трее уведомлением. Такое уведомление
  появляется, даже если уведомления о копировании выключены.

### Стратегии именования файлов

Существующие файлы никогда не перезаписываются. Если копия с таким именем уже есть:

- **Добавить дату к имени** включено — к имени добавляется дата и время в формате `дд.мм.гггг_чч-мм-сс`:
  `Отчет_06.10.2026_14-38-03.docx`;
- **Добавить дату к имени** выключено — к имени добавляется номер: `Отчет_(1).docx`, `Отчет_(2).docx`.

То же правило действует для папки, которая копируется целиком: если папка «Документы» уже есть,
новая копия получит имя `Документы_06.10.2026_14-38-03` или `Документы_(1)`.

**Создавать отдельную папку** создает папку «Резервное копирование дд-мм-гггг». Папка одна на день:
все копирования в тот же день попадают в нее.

### Режимы копирования папок

- **Копировать всю папку** — в назначении создается папка с тем же именем и той же структурой
  (по умолчанию). Для корня диска, например `C:\`, создается папка `Диск_C`.
- **Копировать только содержимое папок** — содержимое папки попадает прямо в место назначения,
  без самой папки.

### Мониторинг процесса

- **Строка состояния** показывает ход копирования, итог и ближайшее копирование по расписанию.
- **Список вкладок** показывает процент у вкладок, которые сейчас копируются.
- **Строка под названием вкладки** показывает ее состояние и следующее копирование.

### История копирования

Блок «История копирования» внизу окна показывает только то, что связано с копированием данных:

- начало каждого копирования: ручное или по расписанию и какие вкладки копируются;
- итог: успешно, с ошибками, не выполнено или отменено, сколько файлов скопировано;
- под итогом с отступом: какие файлы не скопированы и почему, например «файл занят другой программой»,
  а также файлы больше лимита размера и со слишком длинным путем;
- плановое копирование не запустилось и почему;
- пропущенное копирование, которое выполняется после запуска;
- копирование, прерванное закрытием приложения;
- запуск и остановка расписания вкладки.

Пример:

```
06.10.2026 08:55  Расписание запущено: Документы, следующее копирование: 06.10.2026 09:00
06.10.2026 09:00  Плановое копирование: Документы, Фото
06.10.2026 09:02  ✓ Успешно скопировано 152 файла из 2 вкладок
07.10.2026 09:00  ✗ Плановое копирование не запущено (Фото): Не выбрана папка назначения
07.10.2026 09:00  Плановое копирование: Документы
07.10.2026 09:01  ⚠ Скопировано 150 файлов, ошибок: 1
                    Не скопирован C:\Документы\отчет.docx: файл занят другой программой
```

Флажок «Только «Имя вкладки»» оставляет записи, которые относятся к выбранной вкладке. Записи из
истории прежних версий к вкладкам не привязаны и при включенном флажке не показываются.

История сохраняется между запусками в файле `history.txt` рядом с настройками
(Windows: `%LOCALAPPDATA%\BackupApp\history.txt`). Записи старше года удаляются автоматически.
У одного копирования показываются первые 20 файлов с ошибками, остальные есть в подробном журнале.

### Подробный журнал

Кнопка «Открыть подробный журнал» открывает файл со всеми сообщениями программы: служебные записи,
технические подробности ошибок и записи правил безопасности с меткой [SECURITY]. Файл лежит
в `logs/backup-app.log` рядом с настройками (Windows: `%LOCALAPPDATA%\BackupApp\logs\backup-app.log`).
Журнал нужен, если по истории копирования не удается понять причину ошибки.

## Переход с прежней версии

В прежних версиях расписание и параметры копирования были общими на все приложение, а копирование
запускалось кнопками «Запустить», «Остановить» и «Копировать». Теперь расписание и параметры копирования у каждой вкладки свои.
Файл настроек прежней версии переносится автоматически при первом запуске, ничего делать не нужно:

- вкладки, их названия, папки, файлы и папки назначения остаются как были;
- общее расписание (период, время, день недели, число) и общие параметры копирования («Копировать
  только содержимое папок», «Создавать отдельную папку…», «Добавить дату к имени») копируются в каждую
  вкладку;
- если расписание было запущено, оно продолжает работать:
  - при включенной настройке «Копировать данные всех вкладок» — у всех вкладок, где выбраны источники
    и папка назначения;
  - иначе — у вкладки, которая была выбрана;
- время последнего копирования тоже переносится в каждую вкладку, поэтому пропущенное копирование
  после обновления выполнится как раньше;
- автозапуск, фоновый режим, уведомления, пропущенное копирование и лимит размера файла остаются
  общими и переходят на страницу «Настройки»;
- история копирования и подробный журнал сохраняются.

Настройки «Копировать данные всех вкладок» больше нет: вместо нее кнопка «Копировать все вкладки»,
а для копирования нескольких вкладок по расписанию включите расписание у каждой из них.

## Безопасность и защита данных

### Встроенные механизмы безопасности

#### Защита от переполнения путей

- Путь копии не длиннее 240 символов: такие копии открываются в Windows без настройки длинных путей
- Слишком длинное имя файла укорачивается: начало имени и расширение сохраняются, добавляется метка вида `~1a2b3c4d`, чтобы разные файлы не получили одно имя
- Если слишком длинным получается путь самой папки, эта папка пропускается

#### Безопасная обработка символьных ссылок

- **Символьные ссылки и junction внутри выбранных папок не копируются.** Это защищает от бесконечной петли, когда ссылка указывает на свою же папку, и от копирования данных за пределами выбранной папки
- Каждая пропущенная ссылка записывается в журнал
- Скрытые системные ссылки Windows в папке «Документы» («Моя музыка», «Мои рисунки», «Мои видеозаписи») тоже пропускаются, поэтому копирование «Документов» не заканчивается ошибками доступа
- Если ссылку выбрать источником вручную, копируется содержимое, на которое она указывает, а в журнал пишется пометка

#### Защита от выхода за пределы папки назначения

- Путь каждой копии проверяется: файл не может быть записан вне выбранной папки назначения
- Относительные пути с переходом «..» не используются
- Если папка назначения лежит внутри копируемой папки, при обходе она пропускается, поэтому прошлые копии не попадают в новые
- Папка, которая совпадает с папкой назначения, не копируется

#### Проверка типов файлов

- Копируются только обычные файлы и папки
- Специальные файлы Linux и macOS пропускаются: именованные каналы, сокеты, устройства

### Ограничения безопасности

- **Максимальный размер файла**: по умолчанию 2 ГБ. Лимит меняется на странице «Настройки», блок «Безопасность»; значение 0 снимает ограничение
- **Максимальная длина пути копии**: 240 символов
- **Системные папки** нельзя выбрать источником или папкой назначения, а при обходе папок они пропускаются:
  - Windows: папка Windows, Program Files, Program Files (x86) и Recovery на системном диске, а на любом диске корзина `$Recycle.Bin`, `System Volume Information` и файлы `pagefile.sys`, `hiberfil.sys`, `swapfile.sys`
  - Linux: `/bin`, `/boot`, `/dev`, `/etc`, `/lib`, `/lib32`, `/lib64`, `/libx32`, `/proc`, `/sbin`, `/sys`, `/usr`
  - macOS: `/System`, `/bin`, `/sbin`, `/usr`, `/dev`, `/etc`, `/private/etc`, `/cores`

### Мониторинг безопасности

Все события безопасности записываются в журнал с меткой "[SECURITY]":

- пропущенные ссылки и junction
- пропущенные системные папки и файлы
- специальные файлы и файлы больше лимита
- укороченные имена и слишком длинные пути
- небезопасные пути и папка назначения внутри копируемой папки
- ошибки доступа к папкам

Пропуски по правилам безопасности не считаются ошибками. Итог копирования показывает их число, например
«Успешно скопировано 120 файлов; пропущено по правилам безопасности: 3». Ошибки доступа к папкам считаются
ошибками копирования. Если однотипных записей за одно копирование больше 200, в журнал попадают первые 200
и итоговое число.

## Решение проблем

### Общие проблемы

#### Приложение не запускается

**Ошибка**: `ModuleNotFoundError: No module named 'PyQt5'`
**Решение**: Установите зависимости: `pip install -r requirements.txt`

#### Нет прав доступа

**Ошибка**: `PermissionError: [Errno 13] Permission denied`
**Решение**:

- Запустите приложение от имени администратора
- Проверьте права на чтение для исходных папок и запись для папки назначения

#### Недостаточно места

**Ошибка**: «Недостаточно свободного места в … для вкладки '…'» в истории копирования
**Решение**:

- Освободите место на целевом диске
- Выберите другой диск для сохранения копий
- Исключите большие файлы из резервирования

#### Файлы не копируются

**Проблема**: В истории копирования запись «✗ Нет файлов для копирования»
**Решение**:

- Убедитесь, что выбранные папки и файлы существуют (недоступные пути выделены в списке красным)
- Проверьте, что в папках есть файлы (не пустые директории)
- Убедитесь, что у приложения есть права на чтение файлов

#### Кнопка «Копировать сейчас» недоступна

**Причина**: У вкладки не выбраны источники или папка назначения (причина видна под названием вкладки
и в списке вкладок), или уже идет копирование
**Решение**: Добавьте папки или файлы и выберите папку сохранения либо дождитесь конца копирования

### Проблемы с несколькими вкладками

#### Копируются не все вкладки

**Проблема**: «Копировать все вкладки» скопировало только часть вкладок
**Решение**: Вкладки без источников или папки назначения пропускаются. Они отмечены в списке вкладок
оранжевым значком предупреждения с причиной

#### По расписанию копируется не та вкладка

**Особенность**: Расписание у каждой вкладки свое
**Решение**: Откройте вкладку и проверьте переключатель «Копировать по расписанию» и строку
«Следующее копирование: …». Зеленая точка в списке вкладок означает, что расписание вкладки запущено

#### Разные папки назначения

**Особенность**: Каждая вкладка использует свою папку назначения
**Решение**: Проверьте блок «Папка сохранения» каждой вкладки отдельно

#### Частичное завершение

**Проблема**: Некоторые вкладки скопированы, другие — нет
**Решение**: Приложение продолжает работу даже при ошибках в отдельных вкладках. Причины видны в истории
копирования под итогом, полный список — в подробном журнале

#### Общий прогресс

**Особенность**: Полоса хода показывает общий ход по всем вкладкам копирования
**Решение**: Это ожидаемое поведение. Какая вкладка копируется сейчас, видно в строке состояния

### Проблемы с фоновым режимом

#### Окно закрылось, а приложение «исчезло»

**Особенность**: При закрытии окна приложение сворачивается в трей и продолжает работать
**Решение**: Найдите значок в трее (на Windows он может быть скрыт за стрелкой «Отображать скрытые значки»); щелчок по нему открывает окно, «Выход» в меню завершает приложение

#### Нет значка в трее

**Проблема**: Оболочка не поддерживает системный трей (некоторые окружения Linux)
**Решение**: В подробном журнале появляется предупреждение «Системный трей недоступен»; приложение завершается при закрытии окна. Держите окно открытым или свернутым

#### Копирование не выполнилось в назначенное время

**Проверьте**:

- Приложение было запущено (в трее или окном) — расписание работает только внутри приложения
- Расписание вкладки включено: переключатель «Копировать по расписанию» включен, под названием
  вкладки виден зеленый текст «Следующее копирование: …»
- История копирования в окне: в ней видна причина, если плановое копирование не запустилось (нет источников, нет папки назначения, шло другое копирование)
- Если компьютер был выключен, при следующем запуске копирование выполнится автоматически (настройка «Выполнять пропущенное копирование при следующем запуске»)

#### Расписание не включается

**Причина**: У вкладки нет источников или папки назначения — появляется сообщение «Расписание не запущено»
с причиной, переключатель остается выключенным
**Решение**: Добавьте папки или файлы и выберите папку сохранения, затем включите расписание снова

#### Файл или папка не скопированы по правилам безопасности

**Причина**: Сработало одно из правил безопасности: файл больше лимита, системная папка, ссылка или слишком длинный путь
**Решение**: Файлы больше лимита и со слишком длинным путем перечислены в истории копирования под итогом копирования, остальные случаи записаны в подробном журнале с меткой [SECURITY]. Большие файлы копируются после увеличения лимита в блоке «Безопасность» страницы «Настройки»; ссылку можно выбрать источником напрямую; для длинных путей выберите папку назначения ближе к корню диска

#### Системную папку нельзя добавить

**Особенность**: Папки Windows, Program Files и другие системные пути нельзя выбрать источником или папкой назначения — появляется красная плашка с причиной
**Решение**: Выберите свои папки с данными. Если нужен весь диск, выберите его корень: системные папки внутри будут пропущены

#### Копирование завершилось «с ошибками»

**Особенность**: Часть файлов не удалось прочитать (заняты другой программой, нет прав), остальные скопированы
**Решение**: Файлы с ошибками и причины перечислены в истории копирования под итогом копирования, полный список есть в подробном журнале. Закройте программы, которые держат файлы, и повторите копирование

### Проблемы с автозапуском

#### Windows

- Проверьте наличие приложения в списке автозагрузки (Диспетчер задач → Автозагрузка)
- При необходимости настройте вручную через реестр: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- Команда автозапуска содержит флаг `--minimized`; при запуске из исходников используется `pythonw.exe`, чтобы не открывалось окно консоли

#### Linux

- Проверьте файл `~/.config/autostart/backupapp.desktop`
- Убедитесь, что файл имеет права на выполнение

#### macOS

- Проверьте файл `~/Library/LaunchAgents/com.mycompany.backupapp.plist`
- Убедитесь, что приложение разрешено в списке объектов входа (Login Items) в настройках системы

### Проблемы с копированием

#### Много копий одного файла

**Проблема**: В папке назначения появляются `Отчет_06.10.2026_14-38-03.docx` или `Отчет_(1).docx`
**Решение**: Это защита от перезаписи: копия получает новое имя, если файл с таким именем уже есть.
Включите «Создавать отдельную папку «Резервное копирование дд-мм-гггг»», чтобы копии разных дней
лежали в разных папках

#### Длинные пути

**Проблема**: Файлы с длинными путями пропускаются (Windows)
**Решение**:

- Используйте более короткие имена папок
- Выберите папку назначения ближе к корню диска

#### Символьные ссылки не копируются

**Ожидаемое поведение**: Символьные ссылки пропускаются для безопасности
**Решение**: Если нужно скопировать содержимое ссылки, выберите ее источником напрямую

## FAQ

**Где кнопки «Запустить» и «Остановить»?**
Их заменил переключатель «Копировать по расписанию» в блоке «Настройки вкладки»: расписание
включается и выключается у каждой вкладки отдельно.

**Как копировать несколько вкладок по одному расписанию?**
Включите расписание у каждой вкладки и задайте одинаковое время. Вкладки, чье время совпало,
копируются вместе одним копированием.

**Что будет с моими настройками после обновления?**
Они переносятся автоматически, см. [Переход с прежней версии](#переход-с-прежней-версии).

**Удаляет ли приложение старые копии?**
Нет. Резервные копии никогда не удаляются и не перезаписываются. Удаление вкладки и сброс настроек
тоже не трогают ни исходные файлы, ни копии.

**Где хранятся настройки?**
В файле `settings.ini` рядом с историей и журналом: Windows — `%LOCALAPPDATA%\BackupApp`,
Linux — `~/.config/BackupApp`, macOS — `~/Library/Preferences/BackupApp`.
