Многофункциональное кроссплатформенное приложение для автоматического резервного копирования данных с **гарантированной защитой данных** и своим расписанием у каждого набора данных (вкладки).

## 📥 Скачать

Готовые программы для Windows, macOS (Apple Silicon и Intel) и Linux лежат на странице
[последнего релиза](https://github.com/rvburov/backup-desktop-app/releases/latest). Python
ставить не нужно. Что нажать при первом запуске, написано там же, в описании релиза.

## 🛡️ Гарантии безопасности

1. Абсолютная защита данных
	- Исходные файлы никогда не изменяются - только операции чтения
	- Резервные копии никогда не удаляются - полное сохранение истории
	- Автоматическое разрешение конфликтов - переименование вместо перезаписи
	- Нулевой риск потери данных - все версии файлов сохраняются

2. Безопасные алгоритмы копирования
	- Версионирование файлов - автоматическое добавление временных меток
	- Уникальные имена - числовые суффиксы для файлов с одинаковыми именами
	- Изоляция операций - каждая копия создается в отдельном файле
	- Контроль перезаписи - строгая проверка существующих файлов перед копированием

3. Правила безопасности при обходе папок
	- Ссылки и junction внутри папок не копируются: нет петель и копий данных извне
	- Системные папки и файлы не копируются и не выбираются папкой назначения
	- Копируются только обычные файлы; файлы больше лимита (по умолчанию 2 ГБ) пропускаются
	- Путь копии не длиннее 240 символов: длинные имена файлов укорачиваются
	- Копия не может оказаться за пределами папки назначения
	- Все такие события отмечаются в журнале меткой [SECURITY]

## 🌟 Основные функции

1. Вкладки — независимые наборы данных
	- Каждая вкладка: что копировать, папка сохранения, свое расписание и свои параметры копирования
	- Список вкладок слева с состоянием каждой: расписание, ошибка настройки, идет копирование
	- Поиск по вкладкам, когда их больше шести; переименование прямо в заголовке; удаление с подтверждением

2. Управление источниками данных
	- Добавление папок — рекурсивное копирование с сохранением структуры каталогов
	- Выбор отдельных файлов — точечное резервное копирование конкретных файлов
	- Гибкое управление списком — удаление отдельных строк и очистка списка
	- Недоступные и системные пути подсвечиваются в списке и пропускаются, но из настроек не удаляются
	- Настройка папки назначения — выбор целевой директории с автоматическим созданием при необходимости

3. Режимы работы
	- Автоматический режим — переключатель «Копировать по расписанию» у каждой вкладки
	- Ручной режим — «Копировать сейчас» для вкладки и «Копировать все вкладки» для всех вкладок с данными (после подтверждения)
	- Безопасная отмена — возможность прервать операцию без потери данных
	- Фоновый режим — работа из системного трея, уведомления о результатах, запуск свернутым при входе в систему

4. Планирование у каждой вкладки
	- Ежедневное копирование — выполнение в указанное время каждый день
	- Еженедельное копирование — настройка с выбором конкретного дня недели
	- Ежемесячное копирование — планирование с указанием дня месяца (31-е — в последний день короткого месяца)
	- Вкладки, чье время совпало, копируются вместе одним копированием
	- Время следующего копирования видно у вкладки, в строке состояния и в меню трея

5. Дополнительные возможности
	- Временные метки — дата и время в имени копии, если файл с таким именем уже есть
	- Организация копий — автоматическое создание папок "Резервное копирование ДД-ММ-ГГГГ"
	- Пример копии — блок «Так будет выглядеть копия» показывает путь копии с текущими параметрами
	- Автозапуск системы — поддержка автоматического запуска при старте ОС (Windows, Linux, macOS)
	- Контроль ресурсов — проверка свободного места перед началом копирования
	- Перенос настроек — общее расписание и параметры прежних версий автоматически переходят в каждую вкладку

## ⚙️ Технические возможности

1. Управление настройками
	- Сохранение параметров — автоматическое сохранение всех настроек между сеансами работы
	- Восстановление состояния — загрузка предыдущих настроек при запуске приложения
	- Синхронизация интерфейса — полное восстановление состояния элементов управления

2. Мониторинг и отчетность
	- Визуализация прогресса — полоса хода и текущее действие в строке состояния, процент у вкладки в списке
	- Итог копирования — в строке состояния и уведомлением в трее
	- История копирования — в окне видно, когда и что копировалось, чем закончилось и какие файлы не скопированы; фильтр «Только «Имя вкладки»»; записи хранятся год
	- Подробный журнал — все сообщения программы в файле с ротацией, открывается кнопкой «Открыть подробный журнал»

3. Проверки и безопасность
	- Валидация источников — проверка существования и доступности исходных файлов и папок
	- Контроль назначения — проверка доступности и прав доступа к целевой директории
	- Мониторинг места — контроль свободного пространства на целевом диске
	- Обработка сбоев — корректная обработка ошибок доступа и системных исключений

	- Флажки с подсказками — параметры копирования вкладки
	- Подсказки на месте — красная плашка, если путь не принят, короткие сообщения внутри окна, подтверждения удаления, сброса и копирования всех вкладок внутри окна
	- Единое оформление — светлая тема, шрифты Golos Text и JetBrains Mono, четкие иконки на экранах с масштабом 125–200 %

## 🔔 Фоновый режим

1. Системный трей
	- Закрытие или сворачивание окна прячет приложение в трей, расписания вкладок продолжают работать
	- Щелчок по иконке открывает окно; в меню: «Открыть окно», «Копировать все вкладки», время следующего копирования, «Выход»
	- Уведомления о начале планового копирования и о результате: успех, ошибки, отмена
	- Запуск с флагом `--minimized` сразу в трей; автозапуск при входе в систему использует этот флаг

2. Надежность в фоне
	- Пропущенное копирование (компьютер был выключен в назначенное время) выполняется при следующем запуске
	- Новое копирование не запускается, пока идет предыдущее
	- Плановое копирование никогда не открывает диалоговых окон: проблемы попадают в историю копирования и уведомления
	- Ошибка одного файла не прерывает копирование остальных; итог «с ошибками» и список файлов с ошибками видны в истории копирования
	- Защита от второго экземпляра: повторный запуск показывает окно уже работающего приложения
	- История копирования хранится в файле `history.txt`, подробный журнал в `logs/backup-app.log`, оба рядом с настройками (Windows: `%LOCALAPPDATA%\BackupApp`)

## 📊 Особенности реализации

1. Алгоритмы копирования
	- Сохранение структуры — полное сохранение иерархии каталогов при копировании папок
	- Прямое копирование — эффективная обработка отдельных файлов
	- Сохранение метаданных — использование `shutil.copy2()` для сохранения атрибутов файлов
	- Рекурсивный обход — полная обработка вложенных директорий и подпапок

2. Безопасное версионирование
```python
# backup_app/backend/copier.py — никакие файлы не перезаписываются!
def safe_destination_path(path, keep_history):
    if not os.path.exists(path):
        return path
    if keep_history:
        # Добавляем временную метку: file_11.10.2024_14-30-15.txt
        # (если и она занята, добавляется числовой суффикс)
        return f"{name}_{timestamp}{ext}"
    # Добавляем числовой суффикс: file_(1).txt, file_(2).txt
    return f"{name}_({counter}){ext}"
```

3. Управление временем
	- Точное планирование — корректный расчет времени следующего копирования
	- Учет особенностей — обработка сложных сценариев (конец месяца, високосные годы)
	- Регулярная проверка — ежеминутный мониторинг условий для выполнения копирования

4. Обработка ошибок
	- Защита от ошибок — валидация и обработка некорректных путей
	- Стабильность работы — грамотная обработка исключений при операциях копирования
	- Восстановление — автоматическое восстановление работоспособности после сбоев

## 🎯 Сценарии использования

Пример безопасного копирования (вкладка «Документы»: файлы report.docx и data.xlsx, включены
«Создавать отдельную папку…» и «Добавить дату к имени»)
```
Первый запуск 11.10.2024 в 10:00:
📁 Backup/
  └── 📁 Резервное копирование 11-10-2024/
        ├── 📄 report.docx
        └── 📄 data.xlsx

Второй запуск в тот же день в 11:00 — файлы изменены:
📁 Backup/
  └── 📁 Резервное копирование 11-10-2024/
        ├── 📄 report.docx                          ✅ Сохранен
        ├── 📄 data.xlsx                            ✅ Сохранен
        ├── 📄 report_11.10.2024_11-00-10.docx      ✅ Добавлен
        └── 📄 data_11.10.2024_11-00-12.xlsx        ✅ Добавлен

Запуск 12.10.2024 — новая папка дня:
📁 Backup/
  ├── 📁 Резервное копирование 11-10-2024/          ✅ Сохранена
  └── 📁 Резервное копирование 12-10-2024/
        ├── 📄 report.docx
        └── 📄 data.xlsx
```
Без «Добавить дату к имени» вместо даты добавляется номер: report_(1).docx.

## 🚀 Быстрый старт

1. Установка зависимостей
```bash
pip install -r requirements.txt
```

2. Запуск приложения
```bash
python backup-app.py              # открыть окно
python backup-app.py --minimized  # запустить в фоне, иконка в трее
```

3. Первые шаги
	- Переименуйте вкладку «Без названия», щелкнув по названию
	- В блоке «Что копировать» добавьте папки и файлы
	- В блоке «Папка сохранения» выберите папку назначения
	- В блоке «Настройки вкладки» отметьте параметры копирования и проверьте «Так будет выглядеть копия»
	- Включите «Копировать по расписанию» и выберите периодичность, время и день — или нажмите «Копировать сейчас»
	- Для другого набора данных нажмите «Добавить вкладку» на боковой панели
	- Закройте окно: приложение останется в трее и выполнит копирование по расписанию

4. Структура проекта

Бэкенд и фронтенд разделены полностью: вся логика лежит в `backend` и работает без Qt,
интерфейс в `frontend` только показывает состояние и передает команды.
```
backup-app.py              # точка входа
backup_app/
  main.py                  # точка сборки: создает бэкенд и фронтенд
  backend/                 # логика, чистый Python, без Qt
    service.py             # BackupService: настройки, расписание вкладок, запуск, события
    copier.py              # копирование в фоновом потоке
    safety.py              # правила безопасности
    scheduler.py           # расчет времени запуска
    settings_store.py      # настройки (AppConfig, TabConfig), перенос настроек прежних версий
    ini.py                 # формат settings.ini, совместимый с прежними версиями
    autostart.py           # автозапуск для Windows, Linux, macOS
    history.py             # история копирования: файл history.txt, записи за год
    logger.py, events.py, paths.py, constants.py, wording.py
  frontend/                # интерфейс на PyQt5
    app.py                 # QApplication, оформление, одиночный экземпляр, запуск
    bridge.py              # доставка событий бэкенда в поток интерфейса
    theme.py, icons.py     # цвета, шрифты, стили (QSS), иконки
    widgets.py             # готовые элементы интерфейса
    main_window.py         # главное окно: боковая панель, страницы, строка состояния
    tab_page.py            # страница вкладки
    settings_page.py       # страница «Настройки»
    history_panel.py       # история копирования
    tray.py                # иконка в трее, меню, уведомления
    single_instance.py     # защита от второго экземпляра
fonts/                     # шрифты интерфейса и их лицензии SIL OFL 1.1
tests/                     # pytest: backend, frontend и проверка границ между ними
BackupApp.spec             # сборка без консоли: один файл на Windows и Linux, BackupApp.app на macOS
scripts/github-release/    # выпуск релиза: release.sh, проверка версии, история релизов
.github/workflows/         # tests.yml — тесты при каждом push, release.yml — сборка и публикация релиза
```

5. Тесты, сборка и выпуск
```bash
python -m pytest
pyinstaller BackupApp.spec                  # dist/BackupApp.exe, на macOS dist/BackupApp.app
scripts/github-release/release.sh 9.0.1     # выпуск версии: GitHub соберет программы для трех систем
```
