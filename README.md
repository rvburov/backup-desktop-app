Программа для резервного копирования папок и файлов по расписанию на Windows, macOS и Linux.
Исходные файлы только читаются, существующие копии никогда не перезаписываются.

**[Скачать](https://github.com/rvburov/backup-desktop-app/releases/latest)** ·
[Руководство пользователя](docs/README_USER_GUIDE.md) ·
[Руководство разработчика](docs/README_DEVELOPER_GUIDE.md)

## Возможности

- **Вкладки.** Каждая вкладка — отдельный набор данных со своими папками и файлами, папкой
  сохранения, расписанием и параметрами копирования.
- **Расписание.** Каждый день, раз в неделю или раз в месяц в заданное время. Если компьютер был
  выключен, пропущенное копирование выполняется после запуска программы.
- **Без перезаписи.** Если копия с таким именем уже есть, новая получает в имени дату или номер:
  `Отчет_06.10.2026_14-38-03.docx`, `Отчет_(1).docx`. Копии можно раскладывать по папкам дней
  «Резервное копирование дд-мм-гггг».
- **Только новые и измененные файлы.** Повторное копирование пропускает неизмененные файлы,
  а прежняя копия измененного файла остается рядом, с датой в имени.
- **Работа в фоне.** Значок в трее, уведомления о начале и итоге копирования, автозапуск при
  входе в систему.
- **История копирования.** Когда и что копировалось, чем закончилось, какие файлы
  не скопированы и почему.
- **Правила безопасности.** Ссылки и системные папки не копируются, файлы больше лимита
  (по умолчанию 2 ГБ) пропускаются, копия не выходит за пределы папки назначения.

## Установка

Готовые программы лежат на странице
[последнего релиза](https://github.com/rvburov/backup-desktop-app/releases/latest), Python
для них не нужен.

| Система | Файл |
| --- | --- |
| Windows 10 и 11, 64 бит | `BackupApp-<версия>-windows-x64.exe` |
| macOS 11 и новее, Apple Silicon | `BackupApp-<версия>-macos-arm64.dmg` |
| macOS 11 и новее, Intel | `BackupApp-<версия>-macos-x64.dmg` |
| Linux x64: Ubuntu 22.04, Debian 12, Fedora 36 и новее | `BackupApp-<версия>-linux-x64.tar.gz` |

- **Windows**: программа не устанавливается, скачанный файл и есть программа.
- **macOS**: откройте образ и перетащите BackupApp в «Программы».
- **Linux**: распакуйте архив и запустите `./BackupApp`.

Программа не подписана платным сертификатом, поэтому при первом запуске Windows и macOS
попросят подтверждение. Что нажать и как обновиться, написано в описании релиза. Настройки
и история копирования при обновлении сохраняются.

### Из исходников

Нужен Python 3.8 или новее (в CI проверяются 3.11 и 3.12).

```bash
git clone https://github.com/rvburov/backup-desktop-app.git
cd backup-desktop-app
pip install -r requirements.txt
python backup-app.py              # открыть окно
python backup-app.py --minimized  # запустить сразу в трей
```

## Быстрый старт

1. Щелкните по названию вкладки «Без названия» и введите свое, например «Документы».
2. В блоке «Что копировать» добавьте папки и файлы, в блоке «Папка сохранения» выберите,
   куда копировать.
3. Нажмите «Копировать сейчас» или включите «Копировать по расписанию» и задайте время.
4. Чтобы копирование по расписанию шло и с закрытым окном, включите «Фоновый режим работы»
   на странице «Настройки».

Все изменения сохраняются сразу. Для другого набора данных нажмите «Добавить вкладку».

## Разработка

```bash
pip install -r requirements.txt   # PyQt5, PyInstaller, pytest и pyflakes
python -m pytest                  # тесты, дисплей не нужен
pyinstaller BackupApp.spec        # сборка для текущей системы в папку dist/
```

Логика живет в бэкенде на чистом Python, интерфейс на PyQt5 только показывает состояние
и передает команды. Подробно — в [руководстве разработчика](docs/README_DEVELOPER_GUIDE.md).
